# Data Source

This data source is provided from the OM620 Tools and Technology course. The data provided is transaction data that tracks the production of various items to stock for over 784,638 observations. This data shows: The SKU item's inventory type, stocking type, lead time in days, their unit price, manufacturing site, the business ID code assigned to the item, transaction date, and the order quantity within the transaction. 

You can find the transaction data used in the zip file, and the meta data describing the features can be viewed above.
