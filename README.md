# OM620-Tools-Technology
This repository stores the work we have done for my **OM620: Tools and Technology** for Business Analytics course. In this repository, you can view the first two assignments of this course, where we eventually want to calculate the safety stock from provided transactional data. Under the "Assignments" folder, there are two VS Code python notebooks that serve as different steps we take to perform this analysis. 

The data, and it's meta data, can be found under the "Safety_Stock_Assignment" folder. Within the same folder you can see the complete notebook from beginning to end to how we calculate the safety stock based on the completed two assignments.

Please feel free to look through the folders to learn more!
