# OM620-Tools-Technology
This repository stores the work we have done for my **OM620: Tools and Technology** for Business Analytics course. In this repository, you can view the first two assignments of this course, where we eventually want to calculate the safety stock from provided transactional data. 

All within the "Safety_Stock_Assignment" folder, you can find the data, meta data, and completed analysis for this task. Within the same folder you can see the complete VS Code Python notebook from beginning to end to how we calculate the safety stock based on the completed two assignments. These two assignments are under the "Assignments" folder, where you can find two notebooks that served as the different steps we took to perform this analysis. 

Please feel free to look through the folders to learn more!
